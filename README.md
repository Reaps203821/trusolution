# TruSolution

A mental health and peer support mobile application built with React Native (Expo).

## Features

- Onboarding flow for new users
- Mood tracking and progress monitoring
- Peer matching and community support
- Therapist directory with search and booking
- Multiple interaction modes (Ghost, Masked, Open, etc.)
- Privacy and notification controls

## Getting Started

1. Clone the repository
2. Run `cd trusolution && npm install` to install dependencies
3. Run `npx expo start` to launch the development server

## Screens

The app includes screens for:

- Onboarding (3 screens)
- Sign In / Sign Up
- Home, Settings, Profile
- Therapist browsing and booking
- Peer matching and chat
- Mood check and progress tracking
- Various privacy/interaction modes
